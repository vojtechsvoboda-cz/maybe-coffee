# Maybe Coffee – web

One page kavárny Maybe Coffee (Vídeňská 18a, Brno). Statický web na Cloudflare Workers.

- `public/` – web (HTML, CSS, JS, obrázky, fonty)
- `public/data/menu.json` – menu jako data (později je bude upravovat admin)
- `wrangler.jsonc` – nastavení Workeru; push do `main` = nasazení (Cloudflare Builds)

Nadpisy: Owners Wide přes Adobe Fonts (kit `stg5ujl`). Text: Poppins, hostovaný lokálně.
Rezervační formulář zatím nic neodesílá.
